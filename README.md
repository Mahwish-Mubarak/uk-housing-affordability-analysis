UK Housing Affordability Analysis (2015–2025)

 Project Overview

This Power BI project analyzes UK housing affordability and rental market trends between 2015 and 2025.

The analysis combines rental and income datasets to investigate:

* Rental price trends
* Income growth trends
* Housing affordability changes
* Regional rental differences
* Property-type rental trends
* Public vs private sector earnings

The project is presented through two interactive dashboards.

Dashboard 1: Housing Affordability Analysis

This dashboard focuses on:

* Latest Average Rent
* Latest Monthly Income
* Housing Affordability
* Income vs Rent Trends
* Affordability Trends
* Year-over-Year Growth Analysis

Dashboard 2: Regional Rental Analysis

This dashboard focuses on:

* Top 10 Most Expensive Areas
* Property-Type Rental Trends
* Public vs Private Sector Pay Trends
* Area-Specific Rental Analysis

Key Insights

* UK rental prices showed a long-term upward trend between 2015 and 2025.
* Housing affordability deteriorated significantly after 2021.
* Income growth did not always keep pace with rental growth.
* London boroughs consistently recorded the highest rental prices.
* Detached properties remained the most expensive property type.
